# ぱんごっち

パン生地を育てて焼きあげる、ブラウザで遊べる育成ゲームです。

**あそぶ → https://kento-420.github.io/pangotchi/**

## あそびかた

- オーブンの中の生地をお世話します（おなか・しっとり・ぬくもり・ごきげん）。
- パンをタップすると「こねこね」でごきげんが上がります。
- ねむそうなら「ねかせる」、カビが生えたら「ふきとる」、パンくずは掃除します。
- 「あそぶ」で、やきいろ ぴったりゲームができます。
- こねたての間に1回だけ、パウダー（ココア・まっちゃ・いちご・むらさきいも）を混ぜられます。

## しんか

1. 最初の1分の育て方で、生地が3種類（ふわふわ・かため・あまい）に分かれます。
2. 生地と育て方で、焼きあがるパンが13種類に分かれます。
3. 焼きあがりから「もっと そだてる」と、さらに進化します（全26種）。

焼いたパンは「たな」に並びます。記録はブラウザに保存されます。

## つくり

`index.html` ひとつだけで動きます（ビルド不要）。
